# Starbucks clone 

A responsive Starbucks website clone built using React.js and Tailwind CSS, featuring a dynamic shopping cart with local storage integration.

## 🚀 Features

Fully responsive UI with Tailwind CSS

Image slider for product recommendations

Add to Cart functionality with local storage

Toast notifications for user interactions

Smooth animations with Framer Motion


## 🛠️ Tech Stack

Frontend: React.js, Tailwind CSS

State Management: React Context API

Animations: Framer Motion

Notifications: React Toastify

Data Storage: Local Storage

## 🎯 How It Works

Products are displayed in a carousel slider.

Users can add items to the cart.

Cart data is stored in local storage.

Users can remove items or clear the cart.

Total price is dynamically updated.
